# Русификатор SkyFactory 5 — v5.0.8 by Qiota

Полный перевод модпака [SkyFactory 5](https://www.curseforge.com/minecraft/modpacks/skyfactory-5)
(Minecraft 1.20.1, версия пака **5.0.8**) на русский язык.

Переведено всё, что видит игрок: предметы, блоки, мобы, тултипы, книги,
врата, достижения, книга заданий, советы, меню и интерфейс модов.

## Что внутри

| Часть | Объём |
|---|---|
| Предметы, блоки, мобы, GUI, чары, эффекты | **182 lang-файла, ~34 300 строк** |
| Книги Patchouli (Botania, Ars Nouveau, Cyclic, Industrial Foregoing, Mystical Agriculture, големы, Spelled, LaserIO, Forcecraft, RFTools и др.) | **13 книг, ~1260 файлов** |
| Названия врат Gateways to Eternity | **455 шт.** |
| Ачивки, критерии, биомы и тексты самого пака | **~1280 строк** |
| SF5 Things, советы, тултипы цветов, имена мешков | всё |
| Книга заданий Checklist | **345 строк** |
| Ачивки Forcecraft, JEI-страницы | **33 файла** |

Дополнительно закрыто:
- починен битый русский файл Occultism (из-за него весь мод показывался по-английски);
- добиты устаревшие переводы: Botania (+878), Steam Rails (+820), JourneyMap (+205),
  Silent Gear (+280), Draconic Evolution, Cyclic, Immersive Engineering, Vinery,
  Apotheosis, Mystical Agriculture, EnderIO и ещё ~40 модов;
- переведены кнопки главного меню и редкости;
- фирменная механика цветов пака: тултипы, имена мешков, книга — на русском.

## Установка (авто, EXE)

> Перед установкой **закрой игру** — иначе файлы могут не примениться.

1. Скачай **`SF5-Russian-Setup-5.0.8.exe`** из [Releases](../../releases) —
   он автономный, больше ничего качать не нужно.
2. Запусти его.
   Если Windows покажет «Неизвестный издатель» — «Подробнее» → «Выполнить»
   (файл собран из открытого исходника `installer/installer.cs`, вирусов нет —
   антивирус может ругаться на любой неподписанный exe).
3. В окне выбери сборку:
   - обычно она находится **сама** — все найденные instance со словом
     `SkyFactory` в названии попадают в выпадающий список
     (проверяются: `.minecraftx`, CurseForge, PrismLauncher, ATLauncher,
     обычный `.minecraft`);
   - если списка нет — нажми **«Обзор»** и укажи папку instance вручную
     (папка, где лежат `mods`, `resourcepacks`, `config`);
   - кнопка **«Найти»** перезапускает автопоиск.
4. Галочка «Делать бэкапы» — оставь включённой: рядом с каждым заменённым
   файлом сохранится оригинал с расширением `.en.bak`.
5. Нажми **«Установить»**, дождись «Готово», запускай игру.
   В игре: Настройки → Язык → **Русский**.

Тихий режим (без окна): `SF5-Russian-Setup-5.0.8.exe "путь\к\instance"`.

### Что делает инсталятор (по шагам)

1. Копирует ресурспак `SF5_Russian-5.0.8` в `<instance>/resourcepacks/`.
2. Копирует переводы скриптов (`tooltips.zs`, `globals.zs`, 18 файлов
   тултипов цветов, имена мешков) в `<instance>/scripts/` с бэкапами.
3. Копирует русскую книгу заданий в `<instance>/config/checklist/` с бэкапом.
4. Копирует переводы датапака (31 ачивка Forcecraft, 2 JEI-страницы)
   в `global_packs/required_data/skyfactory_5/data/`.
5. Копирует русские описания встроенных паков (6 шт.) в `global_packs/`.
6. Включает ресурспак в `options.txt` (если игра хоть раз запускалась,
   иначе пак включается вручную в меню).

Лог каждого шага виден прямо в окне. Ничего лишнего инсталятор не трогает,
моды (jar) не изменяются вообще.

### Если что-то пошло не так

| Проблема | Решение |
|---|---|
| Сборка не нашлась | Кнопка «Обзор» → выбрать папку instance вручную |
| «Неизвестный издатель» | «Подробнее» → «Выполнить»; либо ставь вручную (ниже) |
| Пака нет в списке ресурспаков | Настройки → Ресурспаки → включить `SF5_Russian-5.0.8` вручную |
| Тексты остались английскими | Проверь язык «Русский» + включённый пак + перезапуск игры |
| Старые мешки называются по-английски | Имя записано в самом предмете — русскими будут новые мешки |
| Хочу откатить | Удали пак из `resourcepacks`, переименуй `.en.bak` обратно |

Запасной вариант — `installer/install-ru.bat` (та же логика, без окна).

## Установка (вручную)

1. Папку `resourcepacks/SF5_Russian-5.0.8` → в `<instance>/resourcepacks/`.
2. Файлы из `scripts-patch/scripts/` → в `<instance>/scripts/` (те же пути).
3. `config-patch/config/checklist/tasks.txt` → в `<instance>/config/checklist/`.
4. Содержимое `datapack-patch/data/` → в
   `<instance>/global_packs/required_data/skyfactory_5/data/`.
5. Включи пак в меню: Настройки → Ресурспаки.

## Важно

- Мешки с добычей, уже лежащие в инвентаре/мире, сохранят старые имена
  (имя записано в NBT). Новые мешки будут русскими.
- Версия перевода соответствует версии модпака: **5.0.8**.
  На других версиях пака часть строк может отличаться.
- Откат: рядом с каждым заменённым файлом лежит `.en.bak`.
- Описания модов в меню «Моды» не переводятся — так устроен Forge.
