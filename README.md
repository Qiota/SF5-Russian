# Русификатор SkyFactory 5 — v5.0.8 by Qiota

Полный перевод модпака [SkyFactory 5](https://www.curseforge.com/minecraft/modpacks/skyfactory-5)
(Minecraft 1.20.1, версия пака **5.0.8**) на русский язык.

Переведено всё, что видит игрок: предметы, блоки, мобы, тултипы, книги,
врата, достижения, книга заданий, советы, меню и интерфейс модов.

## Что внутри

| Часть | Объём |
|---|---|
| Предметы, блоки, мобы, GUI, чары, эффекты | **182 lang-файла, ~34 300 строк** |
| Книги Patchouli (Botania, Ars Nouveau, Cyclic, Industrial Foregoing, Mystical Agriculture, големы, Spelled, LaserIO, Forcecraft, RFTools и др.) | **13 книг, ~1260 файлов** |
| Названия врат Gateways to Eternity | **455 шт.** |
| Ачивки, критерии, биомы и тексты самого пака | **~1280 строк** |
| SF5 Things, советы, тултипы цветов, имена мешков | всё |
| Книга заданий Checklist | **345 строк** |
| Ачивки Forcecraft, JEI-страницы | **33 файла** |

Дополнительно закрыто:
- починен битый русский файл Occultism (из-за него весь мод показывался по-английски);
- добиты устаревшие переводы: Botania (+878), Steam Rails (+820), JourneyMap (+205),
  Silent Gear (+280), Draconic Evolution, Cyclic, Immersive Engineering, Vinery,
  Apotheosis, Mystical Agriculture, EnderIO и ещё ~40 модов;
- переведены кнопки главного меню и редкости;
- фирменная механика цветов пака: тултипы, имена мешков, книга — на русском.

## Состав репозитория

| Путь | Назначение |
|---|---|
| `resourcepacks/SF5_Russian-5.0.8` | сам ресурспак (ставь как есть) |
| `scripts-patch/` | переводы тултипов/имён, генерируемых скриптами (иначе никак) |
| `config-patch/` | русская книга заданий |
| `datapack-patch/` | переводы из датапаков (ачивки, JEI) |
| `installer/` | исходник EXE-инсталятора (`installer.cs`) + bat-запасной |
| `SF5-Russian-Setup-5.0.8.exe` | готовый инсталятор |

## Установка (авто, EXE)

1. Скачай архив из [Releases](../../releases) и распакуй.
2. Запусти `SF5-Russian-Setup-5.0.8.exe`
   (если Windows ругнётся на неизвестного издателя — «Подробнее» → «Выполнить»).
3. Сборка обычно находится сама (список найденных — в окне).
   Если нет — укажи папку instance вручную кнопкой «Обзор»
   (папка, где лежат `mods`, `resourcepacks`, `config`).
4. Нажми «Установить», перезапусти игру.
   В игре: Настройки → Язык → **Русский**.

Тихий режим: `SF5-Russian-Setup-5.0.8.exe "путь\к\instance"`.

Инсталятор сам скопирует файлы, сделает бэкапы оригиналов (`.en.bak`)
и включит ресурспак.

## Установка (вручную)

1. Папку `resourcepacks/SF5_Russian-5.0.8` → в `<instance>/resourcepacks/`.
2. Файлы из `scripts-patch/scripts/` → в `<instance>/scripts/` (те же пути).
3. `config-patch/config/checklist/tasks.txt` → в `<instance>/config/checklist/`.
4. Содержимое `datapack-patch/data/` → в
   `<instance>/global_packs/required_data/skyfactory_5/data/`.
5. Включи пак в меню: Настройки → Ресурспаки.

## Важно

- Мешки с добычей, уже лежащие в инвентаре/мире, сохранят старые имена
  (имя записано в NBT). Новые мешки будут русскими.
- Версия перевода соответствует версии модпака: **5.0.8**.
  На других версиях пака часть строк может отличаться.
- Откат: рядом с каждым заменённым файлом лежит `.en.bak`.
- Описания модов в меню «Моды» не переводятся — так устроен Forge.
